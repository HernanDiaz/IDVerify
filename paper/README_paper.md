## Figures

All figures are generated by scripts in `paper_figures/figures/`:

| File | Generator script | Format |
|------|-----------------|--------|
| `fig0_architecture_compact.pdf` | `architecture_svg_compact.py` → SVG → PDF via svglib | `figure*` |
| `fig1_pareto_front.pdf` | `pareto_front.py` | `figure*` |
| `fig2_nested_cv.pdf` | `nested_cv.py` | `figure*` |
| `fig3_ablation.pdf` | `ablation.py` | `figure*` |
| `fig4_challenge.pdf` | `challenge.py` | `figure*` |
| `fig5_scalar_vs_pareto.pdf` | `scalar_vs_pareto.py` | `figure*` |

To regenerate all figures:
```powershell
cd E:\PycharmProjects\DocVerify
venv\Scripts\python.exe paper_figures\generate_all.py
```

To convert compact architecture SVG to PDF:
```powershell
venv\Scripts\python.exe -c "
from svglib.svglib import svg2rlg
from reportlab.graphics import renderPDF
d = svg2rlg('paper_figures/output/fig0_architecture_compact.svg')
renderPDF.drawToFile(d, 'paper/figures/fig0_architecture_compact.pdf')
"
```

## Compiling

### Windows (MiKTeX)
```powershell
cd paper
.\compile.ps1
```

### Manual 3-pass
```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

### With latexmk
```bash
latexmk -pdf main.tex
```
